# dsh-recent-tabs

[English](README.md) | 中文

DSH Web GUI 的「最近打开」会话 Tab 条，形态参照浏览器标签页：每打开一个会话就
多一个 tab，点 tab 切到该会话，只有你点关闭它才消失。收藏夹是从这条最右端下沉的抽屉，
照浏览器收藏夹的样子放——和浏览器一样，打开中的标签与收藏是两份独立的清单：
关掉标签不会删掉它的收藏。

## 行为

- **鼠标移上去才滑出。** Tab 条默认停在屏幕顶部之外；鼠标移到顶端 10px 触发带，
  它向下滑出，移开后 260ms 收回。阅读对话时不会挡住内容。
- **宽度占屏 90%。** 条占视口横向 90%、在顶缘居中，宽屏因此能多摆几个 tab，而不是
  永远那一小条；仍然摆不下时在条内横向滚动。
- **滚轮横向滚标签。** 指针落在标签行上时，滚轮把标签行横向滚，而不是滚页面——一格纵向滚轮
  就走一段横向距离，不用按 Shift，跟浏览器标签栏一样。滚动不加动画，而且只对标签行本身生效：
  落在收藏夹按钮上或条外时，滚轮一概不管。
- **自动收集。** 从侧边栏、链接或新建会话打开一个会话，就按首次出现的顺序加一个 tab。
- **点击切换。** 当前会话的 tab 带绿点；点其他 tab 即切到该会话。
- **三个状态标记。** 标题前只有一个槽位，同一时刻只出一个标记。正在执行的 tab 会在标题前
  转一个柔和蓝色的小圈；回合在你看着别处时结束的 tab，同一位置改留一个小而静的蓝色对勾——
  「回答好了、还没看」的提醒，这让「答过的」与「从没跑过的」tab 一眼可分；会话在等你回答某个
  提问或计划评审时，同一位置再换成一个小而静的蓝色问号——不回它，这一轮就动不了。问号压过另外
  两个回合事实（它是唯一需要你动手的那件事），执行中的转圈压过对勾；三个标记都不动画，三者都
  没有时 tab 回到原样。三个标记只出现在 tab 条上，绝不进对话流。
- **手动关闭。** 只有点关闭按钮才移除 tab，所以 tab 条就是你尚未关掉的那批会话。
- **收藏是独立的一份清单。** 收藏不是 tab 行上的标记，而是单独存的一条条目。在 tab 条里
  关掉标签只关标签：该会话仍留在收藏夹抽屉里，随时可以再打开。
- **拖动排序。** 把一个 tab 拖到另一个 tab 上，指针落在左半边还是右半边决定插到它前面
  还是后面，拖动时目标那侧会亮出插入边。tab 条记住的就是这个新顺序，拖动过程不会切换会话。
- **收藏夹是从条上打开的紧凑抽屉。** Tab 条的最右端有一颗 `收藏夹` 按钮（星标 + 文案），
  落在横向滚动区之外，所以标签再多也不会把它滚走。点它在条的这一端下方打开一个 200px 宽的
  紧凑面板：高度随内容，最多 60vh 或 520px，条目多了在面板内部滚动，不会一路铺到屏幕底。
  抽屉开着时，即使鼠标移开，条子也会留在屏上——抽屉锚定的按钮挂在条上，条子一收回锚点就跑到
  屏幕外；关掉抽屉后恢复原来的 260ms 收回。抽屉按按钮自身的矩形定位，按钮因布局变化移动时
  抽屉跟着走，不会留在原地。Esc、点抽屉外、再点一次按钮都能关；关着的时候抽屉不占任何 DOM。
- **书签栏的观感。** 条子读起来是一条薄架子而不是卡片：紧凑的 tab 悬停时换一层圆角高亮，
  底下一条细边线、下方 9px 圆角、单层轻投影，绝不描四边框。收藏在这条中性条里有一套自己的
  配色：`收藏夹` 按钮上的星形常驻强调色，外面一圈蓝色细边，悬停加深、抽屉开着时再铺一层
  蓝色淡化底；抽屉是纸片式 popover——蓝色细边、蓝色标题加标题下一条蓝色细线、平底的
  行悬停才亮起、当前会话铺蓝色淡化底。这抹蓝取的是 shell 自带的交互蓝（和链接、信息按钮
  同一个色系），再掺进它所在的表面柔和一档：原色取 85%、掺进主题纸片色，色相留住、明度
  降下来，两套主题里都沉着而不刺眼。它也是本插件唯一加的色相——shell 的 brand 色在这套
  主题下解析成纯黑，拿它当强调色等于没有强调。
  只有这些装饰带色：面板底色、tab 与条本身保持中性。
  它的层级高于条子本身与标签右键菜单，开着时不会被其中任何一个切开。全部取自 shell 的
  alias token，两套主题都按原样生效。
- **两种收藏方式。** 抽屉里的星标收藏或取消收藏**当前会话**；在顶部标签条里右键任意
  标签，小菜单里选 `收藏` / `取消收藏`——这一项带同一套收藏强调色，已收藏时字重加重。
  两个入口写的是同一份收藏清单。条上那颗星只负责打开抽屉，收藏也不会改变 tab 顺序。
- **抽屉里面。** 收藏项按存储顺序竖排；你正在看的那个会话带一个绿点（就是条上 tab 用的那颗绿点）
  并铺一层蓝色淡化底：点条目打开该会话，悬停出现的 `×` 只取消收藏（tab 与会话都还在），
  上下拖动条目排序。会话已失效的条目仍在，置灰并加删除线，直到你取消收藏。一条收藏都没有时，
  抽屉会写清上面两个入口。
- **收藏夹里能建文件夹，像浏览器书签那样。** 星标旁边那颗 `+` 在根层建一个文件夹，并立刻把名字
  放进编辑器：直接打字回车（Esc 保留默认名）。点文件夹行展开/收起，双击名字就地重命名，悬停出现
  的 `×` 删掉这个文件夹连同里面全部内容——那些会话的 tab 照旧留在条上。子项缩进挂在文件夹下面，
  仍是同一个滚动列表，嵌套不会多出第二个滚动区。把收藏项拖到文件夹行上就归进去（文件夹会自动
  展开，看得见落在哪），拖到另一个收藏项上是在本层内排序，把文件夹拖到另一个文件夹上是嵌套，
  把文件夹拖到某个收藏项上则让这个文件夹搬进那一行所在的层——文件夹不能拖进它自己或它自己的
  子文件夹。展开与否只是视图状态：关掉抽屉再打开还记着，刷新页面不记。
- **关掉当前 tab 回退到 MRU。** 关掉你正在看的那个 tab，视图切回上一个用过的 tab
  （最近使用顺序）；关其他 tab 不影响当前视图。若一个都不剩，视图保持不变。
- **双击就地重命名。** 双击 tab 改名字；回车或点别处提交，Esc 取消。改的是**会话真名**，
  不只是 tab 显示——所有读取会话标题的列表都会跟着变。失效 tab（会话已不在列表）
  不能重命名。
- **宽度固定。** 每个 tab 固定 150px，标题长短不会让整排重排；过长标题省略号。
- **跨重启保留。** 两份清单都存在浏览器 `localStorage` 的 `dsh-recent-tabs-v1`
  键下，合成一条 `{ tabs, favorites }` 记录——其中 `favorites` 是收藏树的根层，收藏项与
  文件夹并排放在这一层——刷新页面或重启 GUI 后仍在，关闭浏览器也不会丢。顺序、收藏条目与
  文件夹结构都记在这份数据里；文件夹展开与否、抽屉开着还是关着都不落盘。旧版本写下的数据
  （裸 tab 数组、每行带 `favorite` 标记）在首次加载时迁移：每一行都留在 `tabs` 里，
  带标记的行**同时**进 `favorites`——一行本来既是一个 tab 又是一条收藏，收藏从不关闭
  标签——两个桶各自去重、各自保序；改写前先把原文照抄到 `dsh-recent-tabs-v1-backup` 键。
  文件夹出现之前存下的收藏列表本身就是一棵没有文件夹的树，所以完全不需要迁移。
- **失效会话仍在。** 已从会话列表消失的保留 tab 继续显示，置灰并加删除线，
  直到你手动关闭。

## 挂载位置

两处追加注册，都不覆盖官方条目：

| 槽位 | 表面 |
| --- | --- |
| `shell.overlay` | Tab 条，位于所有列之上、各列滚动容器之外。`收藏夹` 按钮由它自己渲染在条的最右端。 |
| `shell.overlay` | 收藏夹抽屉，与 Tab 条同一个 list 槽位的兄弟条目。 |

按钮属于条本身，不是一处独立注册：它就在这一行里、在横向滚动区之外的最右端，抽屉因此挂在
条的右角下方。标题栏不加任何东西，也就不存在遮住官方标题栏槽位的问题。两处注册各自包一层
`try`/`catch`——某处挂载失败只降级那一个表面，绝不会带崩整个 shell。

按钮与抽屉是分开挂载的，所以开合状态放在 `fav-drawer-state.ts`——模块级 observable，
纯 UI 状态，不落盘。Tab 条也订阅它：抽屉开着时条子钉在屏上，否则收回的条子会把抽屉的
锚点带到视口之外。

## 结构

| 半区 | 文件 | 职责 |
| --- | --- | --- |
| Host | `src/index.ts` | 空实现。功能全在浏览器侧。 |
| Client | `src/client/index.ts` | 注册双语字典，并分别挂载两个表面（Tab 条、抽屉），各带 `try`/`catch`。 |
| Client | `src/client/RecentTabs.tsx` | React Tab 条：单行 tab、条最右端的收藏夹按钮、滑出与拖拽状态、就地重命名、标签右键菜单；抽屉开着时还负责把条子钉在屏上。 |
| Client | `src/client/FavoriteButton.tsx` | 条右端的按钮：星标 + 文案，`aria-haspopup="dialog"`、`aria-expanded` 绑抽屉开合。 |
| Client | `src/client/FavoritesPanel.tsx` | 抽屉：按按钮矩形锚定、收藏当前会话、绘制收藏树、新建与重命名文件夹、竖排拖拽并把行归入文件夹。 |
| Client | `src/client/fav-drawer-state.ts` | 按钮、Tab 条与抽屉共享的开合状态；纯 UI 状态，不落盘。 |
| Client | `src/client/fav-folder-state.ts` | 展开了哪些文件夹的模块级集合；纯 UI 状态，不落盘。 |
| Client | `src/client/use-current-session.ts` | Tab 条与抽屉共用的会话视图（选中项、实时 id、标题、运行事实）。 |
| Client | `src/client/drag-place.ts` | 插入边判定：Tab 条按左右，抽屉竖排按上下。 |
| Client | `src/client/controller.ts` | 两份存储清单的快照持有者；仅在真变化时通知。 |
| Client | `src/client/store.ts` | 纯逻辑（无框架依赖）：解析与迁移、tab、收藏树（含文件夹）、排序、读写。 |

会话数据来自 Session Controller 的 `ctx.sessions.list` 快照源与 `ctx.uiWorkspace.openSession(id)`。
这些表面是全局的，而 Slot props 是会话作用域的，因此刻意不走 props 里的 `useSessions`。

持久列表是**成员资格**的唯一事实源；实时会话列表是**标题与存在性**的事实源。
这个分工让保留的 tab 能在会话消失后仍保住最后一次已知的名称。

收藏是独立的一份清单，不是持久行上的一个字段。它是一棵树：`favorites` 是根层，文件夹是
一种能装收藏项与子文件夹的节点。`toggleFavorite` 把会话加在根层，取消时删掉它所在的那一行
（不论在不在文件夹里）；`moveFavorite` 只在同一层里重排兄弟；文件夹操作（`createFolder`、
`renameFolder`、`removeFolder`、`moveFavoriteInto`、`moveFolderInto`）也只改这棵树。
它们都不动 tab 列表、也不动激活顺序——这正是「关掉 tab 不会丢收藏」的来处。

右键菜单由本插件自绘，不用官方菜单组件：`position: fixed` 定在点击处并夹进视口，
不带任何官方类名。

## 快速来回切换

记录会话是幂等的：`recordTab` 与 controller 在观测没有带来变化时都返回同一个快照
引用，并且只在真变化时通知订阅者。因此在两个 tab 间来回点不会重入渲染循环——这正是
本插件早期作为动态插件时出现抖动的原因。

## 安装

从 npm 安装，或从任何收录了它的插件市场安装：

```sh
dsh plugin --profile web add dsh-recent-tabs
```

或从源码目录作为本地 bundle 安装：

```sh
dsh plugin --profile web add link:<repo>/my-plugins/dsh-recent-tabs
```

随后重启该 profile，让 Host 半区注册。

## 本地检查

```sh
pnpm --filter dsh-recent-tabs typecheck
pnpm --filter dsh-recent-tabs test
pnpm --filter dsh-recent-tabs build
```

## 限制

- Tab 条列的是**本浏览器**打开过的会话。换浏览器、换 profile 或开隐私窗口各有自己的列表。
- 存储是尽力而为：浏览器若禁用 `localStorage`（部分配置的隐私模式）或配额异常，
  Tab 条在当前页面生命周期内仍可用，但不持久化。
- 列表上限 40 个 tab，超出后最早的会被丢弃。
